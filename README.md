# GR Connective | Business Profit Calculator

## Publicación gratuita (GitHub Pages)
1. Descomprime el ZIP.
2. Crea un repositorio público en GitHub y sube los cuatro archivos (`index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`) a la raíz.
3. En **Settings → Pages**, elige **Deploy from a branch**, rama **main**, carpeta **/(root)** y guarda.
4. Abre la URL HTTPS publicada (habitualmente `https://USUARIO.github.io/REPOSITORIO/`).
5. En iPhone abre la URL con Safari → Compartir → **Añadir a pantalla de inicio**.

## Modelo
Ventas = ventas diarias × días. Ventas automáticas = clientes × ticket. Gastos variables = ventas × suma de porcentajes. Ganancia operativa = ventas − gastos variables − gastos fijos. Equilibrio = gastos fijos / (1 − tasa variable). Meta de ventas = (gastos fijos + ganancia deseada) / (1 − tasa variable). El retorno mensual sobre inversión = ganancia operativa / inversión inicial.

El catálogo de productos es independiente de las ventas globales para no duplicar costos. El costo de combustible se modela como porcentaje de ventas. La estimación semanal usa 12 meses / 52 semanas. No incluye impuestos, depreciación, financiación ni cambios estacionales. El PDF se obtiene con la función de imprimir/guardar como PDF del navegador.

Los escenarios guardados quedan únicamente en localStorage de ese navegador y pueden perderse al borrar los datos del sitio.
